# Manual Habitación Llena — actualización v0.4

## Cambios incorporados desde v0.3

### Permisos granulares por acción

Configuración -> Roles y permisos ahora separa **Módulos** de **Acciones** para reducir carga visual. El primer corte controla tanto interfaz como backend para crear links de cobro, verificar/conciliar cobros, administrar claves API e invitar usuarios.

### Channel Manager Health Center

El Channel Manager incorpora un Health Center basado en telemetría real. Resume **General, Última sync, Cola y Conflictos**. El diagnóstico expandido muestra mapeos, flujo PMS -> OTAs, OTAs -> PMS y sincronización, con acción **Resolver** cuando corresponde.

### CRM y fidelización

Huéspedes usa segmentos compactos en lugar de tarjetas grandes. El perfil 360 incorpora consentimiento comercial separado para **Email** y **WhatsApp**, más oportunidades contextuales como cumpleaños. Las campañas y automatizaciones comerciales siguen en desarrollo.

### Cartera multi-propiedad

Cartera prioriza **Pendientes ahora**: mantenimiento urgente, unidades por limpiar y llegadas, cada una con acceso directo al módulo correspondiente. Se incorpora metadata por propiedad para **tipo operativo** y **dirección**, especialmente útil para operadores Airbnb/alquiler vacacional con unidades dispersas.

### Criterio UX actualizado

La pantalla diaria debe mostrar estado, dato importante y acción. La explicación larga se mueve a Ayuda/manual. Configuración avanzada queda fuera del camino operativo principal.
